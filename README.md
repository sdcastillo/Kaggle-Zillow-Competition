# Kaggle Zillow House Prices Hackathon

This repository contains code and experiments for the Zillow Prize Kaggle hackathon, a large-scale competition to predict residential home values.  
https://www.kaggle.com/c/zillow-prize-1

## From hackathon to industry

Participating in this competition was an important early step in my journey as a data scientist and engineer. Working with messy real estate data, feature engineering, and model evaluation in a competitive setting helped build practical skills that go far beyond what most traditional coursework covers.

After this project, I went on to work at Expedia Group, where I had the opportunity to work with datasets covering millions of properties around the world. The same instincts developed in Kaggle hackathons—experimenting quickly, validating rigorously, and shipping models that matter—translated directly to production work on large-scale, real-world systems.

Experiences like Kaggle hackathons do not replace a master’s degree, but they can prepare you for the realities of data science and machine learning jobs in ways that are often more hands-on and immediately applicable than classroom work alone.
